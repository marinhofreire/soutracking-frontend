# SouTracking — Referência Visual Frontend Novo

Data: 22/05/2026
Objetivo: servir como referência visual única para implementação pixel-perfect do frontend SouTracking.

## Ordem das telas
1. Mapa
2. Veículos
3. Equipamentos / Dispositivos
4. Telemetria operacional
5. Alertas operacionais
6. Cercas eletrônicas
7. Relatórios
8. Comandos remotos
9. Manutenção
10. Comunicação operacional
11. Logs / Data Log
12. Configurações
13. Dashboard

## Regras visuais obrigatórias
- Sidebar branca translúcida fixa à esquerda.
- Mapa/fundo sempre aparecendo por baixo, sutil.
- Cards brancos translúcidos com borda suave e sombra leve.
- Topbar com busca, indicadores e perfil no topo.
- Cantos arredondados e espaçamento limpo.
- Não voltar ao layout antigo.
- Implementar primeiro camada visual estática fiel às imagens.
- Depois ligar dados reais, mapas e ações.

## Regra operacional
Antes de mexer no código principal, matar servidores locais antigos, subir uma única instância limpa e validar rota por rota.
