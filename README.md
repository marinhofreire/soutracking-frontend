# soutracking_flutter

App Flutter para gestão de frotas com integração Traccar.

## Recursos

- Login com sessão do Traccar
- Dashboard com cards de status
- Lista de veículos
- Mapa (placeholder)
- Configurações com base da API

## API

Base padrão: https://app.mackflow.com.br/api

## Como rodar

1) Instale as dependências:
	flutter pub get

2) Execute o app:
	flutter run
